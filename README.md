🎮 Sobre o Projeto

Pixel Soccer é um jogo de futebol com inspiração nos clássicos jogos de plataforma da era 8-bit, trazendo uma combinação de futebol, aventura e nostalgia.

Prepare-se para entrar em campo, enfrentar desafios, coletar itens e explorar um universo inspirado nos antigos videogames, com personagens pixelados e uma atmosfera retrô.

A proposta é unir a diversão dos jogos clássicos de plataforma com elementos tradicionais do futebol, criando uma experiência leve, divertida e nostálgica.

🏆 Funcionalidades

⚽ Mecânicas de futebol em um ambiente de plataforma.

🕹️ Estética retrô inspirada nos jogos 8-bit.

👾 Personagens e cenários em pixel art.

💥 Sistema de combate e interação com inimigos.

🎁 Coletáveis e sistema de munição.

🎵 Experiência inspirada nos videogames clássicos.

🛠️ Tecnologias

Godot Engine — desenvolvimento do jogo.

GDScript — programação das mecânicas e funcionalidades.

Git e GitHub — versionamento e gerenciamento do projeto.

🚀 Objetivo

O objetivo do projeto é desenvolver um jogo divertido, explorar conceitos de desenvolvimento de jogos e aprimorar conhecimentos em lógica de programação, física, animações, colisões e desenvolvimento com Godot.
